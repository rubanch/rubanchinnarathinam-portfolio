# Simple React portfolio

Install Node.js, then run `npm install` and `npm run dev`. Open the local URL shown by Vite. Run `npm run build` to create the static site in `dist/`.

Update your name, email, links, skills, projects, experience and recognition in `src/data.js`. Example projects and career details are starter placeholders: replace them with accurate information before publishing. This is a static site and needs no server or database.

To publish on GitHub Pages, push the project to a GitHub repository and configure Pages to use GitHub Actions. For project pages, build with `VITE_BASE=/<repository-name>/ npm run build`.
